# Landing Page - Consultoria 360

Esta landing page foi desenvolvida para o Instituto FNC, uma empresa de marketing que busca apresentar uma prévia online de seus serviços para engajar leads e nutrir relacionamento com potenciais clientes.

## Como Visualizar

1. Clone o repositório:

    ```bash
    git clone https://github.com/JonatasVieiraa/LP_Consultoria360-.git
    ```

2. Acesse o diretório:

    ```bash
    cd LP_Consultoria360-
    ```

3. Abra o arquivo `index.html` no navegador para visualizar a landing page.

## Estrutura do Projeto

- **index.html**: Estrutura principal da landing page.
- **styles.css**: Estilos que garantem um design moderno e atraente.
- **script.js**: Funcionalidades interativas para engajar os leads.

## Finalidade

Esta landing page foi projetada para compartilhar informações essenciais da Consultoria 360, oferecendo uma visão geral dos serviços de maneira atraente e eficiente ao público-alvo.
